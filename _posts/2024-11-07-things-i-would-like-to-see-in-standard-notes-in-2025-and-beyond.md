# Things I would like to see in Standard Notes in 2025 and beyond

<div class="meta">November 7, 2024</div>

As someone who uses Standard Notes their main notes app, below are things I'd love to see come to Standard Notes

### Sharable notes via a secure URL
It would be great if Standard Notes could add a feature that allows users to share notes via a secure URL. Currently, the only way to do this in Standard Notes is by making a private Listed.to post. This requires an extra step of having to make a Listed author page.

Proton Drive recently introduced docs sharing via URL. As Proton Docs is being developed by the Standard Notes and Proton team, hopefully they can finally build this feature directly into the Standard Notes application.

### Note tabs / windows
Another feature that would be useful is the ability to have multiple notes open at once. I often find myself having to reference back to another note in my Standard Notes account. Having note tabs or the ability to open another note in another window and have them side by side would make things to much easier - with the added bonus of increased productivity.

### The ability to align images inside a note and easily resize them by dragging the cursor from the corner
It would be great if Standard Notes could add a feature that allows users to align images inside a note and resize them by dragging the cursor from the corner. This would make for more visually appealing notes. The current implementation is fine and does the job, but I feel this area could be improved much further.

### Update UI
Let's be honest, the current Standard Notes UI is okay. It's simple enough and gets the job done. However, I feel that the UI for Standard Notes is starting to get a bit outdated. Hopefully in the future it can get a more modernised look - preferably a UI similar to other Proton app
